**gamechase** [demo link](https://shreykz.itch.io/gamechase)

gamechase is a retro arcade type game build using godot, which features a character that moves to capture berries. you have got ten seconds, score as much as possible!

**how to play?**

to play gamechase, you just have to install its executable from [itch.io](https://shreykz.itch.io/gamechase) on a windows computer, or compile it yourself using this repository (just open the godot engine if you already have it and export the project using your preferred traces). run the .exe file and click on the start button. the fun part is *not* knowing where the berries will appear.

*or*

you can simply just play it without leaving your browser, if you don't want to install anything.

**making the game**

building the game involved me learning a lot of things i didn't earlier understood :) nodes, linking them with gdscript etc. there were challenges, but also the debugger. 

**technologies**

i used the [godot game engine](https://godotengine.org/) to build this game. godot is a very capable one when it comes to 2D/3D games!

i used AI to generate parts of this code's gdscript, the scripting language for godot. no assets or any in-game media was made using AI.
